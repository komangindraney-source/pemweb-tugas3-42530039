# Tugas 3 - Pemrograman Web (CRUD Node.js & MySQL)

Aplikasi web sederhana untuk manajemen data mahasiswa menggunakan **Node.js**, **Express.js**, **MySQL2 (Connection Pool)**, dan **EJS** dengan menerapkan keamanan *Prepared Statements* dan alur *Post-Redirect-Get (PRG)*.

## Struktur Proyek
- `app.js` - Berkas utama server Express.js dan routing CRUD.
- `db.js` - Konfigurasi koneksi database MySQL menggunakan connection pool.
- `database.sql` - Skema basis data dan data sampel awal.
- `views/index.ejs` - Antarmuka pengguna (Frontend templating).
- `public/style.css` - Berkas gaya (CSS) eksternal.
